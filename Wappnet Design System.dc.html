04

Layout

Container

max-width:1200px; margin:0 auto; padding:0 24px on every section's inner wrapper. Full-bleed rows (industries, CTA, marquee) put the background on the section and keep text inside the container.

Card gaps

24px between cards, 20px between tight tiles, 40–64px between columns of a split layout.

Breakpoints

Desktop nav / 3-up grids≥ 1180
Mega-menu promo beside grid≥ 900
Nav → Menu button< 980
4-up → 2-up< 980
2-up → 1-up< 560

Column counts are set in JS

Any row that must not orphan a card (industries, capability tiles, offices, depth columns, menu grid) reads window.innerWidth in componentDidMount/resize and writes gridTemplateColumns. auto-fit is only for rows where a wrap is harmless.

Every text cell in a grid gets minmax(0,1fr) so long labels wrap instead of overflowing.

11

Motion

Scroll reveal
Mark a block data-reveal. Hidden state opacity:0; translateY(22px), transition .7s cubic-bezier(.16,1,.3,1). Stagger siblings with data-reveal-delay="90ms". Only elements below the fold are hidden.
Reveal plumbing
A sweep on scroll plus a 220ms ticker that stops when nothing is pending, data-revealed so re-renders cannot re-hide, and a 2.6s fallback that shows everything.
Hover
Cards lift 4–6px with a shadow. Buttons lift 2px. Tiles expand 2:1:1 over .55s cubic-bezier(.16,1,.3,1). Images cross-fade over .5s ease. Set ref styles synchronously in the handler so the paint is immediate.
Named keyframes
panelIn .22s dropdowns · fadeUp .4s revealed tile content and carousel slides · marquee 28–30s logo strips. No other animations.
Counters
Cubic ease-out over 1.1s, once per element, skipped while document.hidden, with a 1.4s snap to target. Static markup holds the final number.
Carousel
Auto-advance every 5.2s, arrows reset the timer, an n / total counter is always visible.

Scrims
Text over a photo always sits on a bottom-weighted scrim: linear-gradient(180deg,transparent 0,transparent calc(100% - 230px),rgba(13,13,15,.86) 100%), applied per cell rather than per row.
Icons
Line marks only, 24-unit viewBox, stroke 1.4–1.5, round caps and joins, in #E8541F on light or #fff on ink. No filled icons, no emoji.
Logos
Trim to the alpha bounding box before use — padded canvases make one logo look smaller than its neighbour. Coloured marks sit on a white plate, never on ink or gradient.
13

Voice

How we write

Concrete over abstract. Name the thing, the timebox or the number.
Headings 24 characters wide, one idea each.
Every card description is one sentence. Every FAQ answer opens with the answer.
British spelling, sentence case everywhere except eyebrows.
Numbers as digits. Timeboxes as weeks, not "rapid".

Words we avoid

cutting-edge seamless revolutionary unlock empower end-to-end solutions synergy game-changing

CTA labels in use

Request a quote · Talk to an AI expert · Start with one use case · Book the call · Scope a use case · Learn more · See what we built

Findability

One H1 per page, section H2s that read as real questions or claims.
FAQ answers front-load the answer so an AI summary can lift the first sentence.
Emit FAQPage JSON-LD wherever an accordion exists; Organization and Service on the relevant pages.
Every stat and claim must be attributable. Mark unverified figures as placeholders rather than shipping them.
14

Rules

Always

One primary CTA per view, above the fold in the hero.
white-space:nowrap on every button label, chip and stat caption; flex:none on every arrow.
minmax(0,1fr) on text cells in a grid.
Fixed column counts via JS for any row that must not orphan.
Section heading spec exactly as in section 02.
Real export sizes in every image placeholder.

Never

A third gradient, or a 3-stop warm gradient.
Two dark bands touching, or two gradient bands on one page.
A new radius, shadow or type size that is not on this board.
Emoji, filled icons, drawn illustrations standing in for photography.
Invented client names, logos or metrics.
A dropdown taller than the viewport.

Before shipping a page

Check 1440, 1180, 980, 760 and 390 wide, and one 1366×768 laptop.
Confirm the hero CTA needs no scroll at 768px tall.
Open every dropdown at 768px tall.
Scroll once to confirm reveals fire and never re-hide.
Confirm no heading exceeds two lines at 1440.
